# Привычка / Ritualr — трекер привычек

## Продукт
Веб-приложение для отслеживания привычек и анти-привычек. Работает в браузере, данные хранятся в облаке. Название на русском — **Привычка**, на английском — **Ritualr**.

## URL
https://ritualr.vercel.app

## Бренд

**Теглайн (EN):** "Repeat until it's you."
**Теглайн (RU):** «Привычка, которая меняет всё.»

**Позиционирование:** Identity-based habit theory — не просто галочки, а становление собой. Простой и красивый трекер, который не перегружает. Без подписки, без рекламы.

**Tone of voice:** Дружелюбный, мотивирующий, честный. Без корпоративщины и пафоса. Говорит с пользователем как близкий друг, который верит в него.

**Цвета:**
- Midnight #101585 — основной, хедеры, кнопки
- Dusk #2D22C4 — вторичные действия, карточки
- Lavender #A78BFA — прогресс, мягкие акценты
- Haze #EDE9FF — фон
- Spark #FFDD44 — стрики, достижения, праздник

## Целевая аудитория
Люди 20–40 лет, которые хотят изменить свою жизнь через маленькие ежедневные действия. Уже пробовали приложения для привычек, но бросали — было сложно или скучно.

## Ключевые функции
- Трекинг привычек с визуальным прогрессом по дням недели
- Анти-привычки — отслеживай то, чего НЕ делал (не курил, не ел сладкое, не прокрастинировал)
- Группы привычек (здоровье, спорт, работа, личное)
- Стрики и достижения — мотивация не бросать
- Вход через Google — без паролей
- Работает без входа (данные в браузере), с входом — история сохраняется в облаке
